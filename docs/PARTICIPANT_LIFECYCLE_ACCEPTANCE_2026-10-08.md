1. Delayed Student A detail overwrote later selected Student B. Separate list/detail generations now discard stale responses, clear confirmation state and guard unmounts.
2. A participant-list 503 retained old rows and usable lifecycle controls. Loading/failure now removes stale selection; failed refresh removes records; mutation controls are frozen during save. A failed post-mutation refresh cannot restore the old participant detail.
3. Dossier API supplied lifecycle fields, but the screen omitted effective date and internal reason/actor/audits. `StudentLifecycleSummary` now renders the existing payload with explicit internal visibility gating and Malaysia timestamps. Public rendering remains private even if the frontend object contains extra fields.
4. Supervisor Office cancellations projected as Pending; assigned Lecturer history omitted cancellation before any Lecturer decision. Both projections now recognize `CANCELLED_BY_OFFICE`. Ended Supervisor table rows previously fell through to Rejected; they now show Ended. Attempt identity replaces Student ID as the row key. Cancellation chips use Cancelled without attributing the action to a Student.
5. Panel Office cancellations projected as Approved and were omitted from selected Panel history before a decision. Backend projections and shared frontend status contracts now recognize `CANCELLED_BY_OFFICE`; the Cancelled chip no longer attributes the action to the Supervisor. Browser Lecturer history shows both cancelled requests, Cancelled by Office and Cancelled before decision, and the Cancelled filter retains them. Student Supervisor history maps Office cancellation to terminal Cancelled. A further regression reproduces cancellation after Panel acceptance incorrectly showing rejection; both timeline builders now preserve the accepted Panel step and show cancellation during Coordinator confirmation. That after-acceptance variant has automated coverage; it was not added to the browser transition matrix.

The late-selection, refresh-outage, ended-row and dossier regressions were observed failing before correction and passing afterward.
